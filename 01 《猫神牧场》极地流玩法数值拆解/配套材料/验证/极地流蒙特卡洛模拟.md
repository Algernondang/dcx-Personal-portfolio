# 极地流蒙特卡洛模拟

在《猫神牧场》的极地流中，企鹅的雪球必须先冻住目标，猛犸象解冻后才能触发下一轮出手。这里比较每轮随机排列企鹅与每轮按固定顺序出手时，启动期冻结覆盖和雪球分布的变化。

## 实验设定

| 项目 | 模型规则 |
| --- | --- |
| 阵容 | 2 至 6 组，每组 1 只企鹅和 1 只猛犸象。 |
| 样本 | 每种顺序、每种阵容各初始化 1,000 条轨迹。每条连续运行 30 回合。同一条轨迹内，企鹅雪球数跨回合累积。 |
| 出手 | 首轮全体企鹅出手。解冻后，上一轮被冻住的企鹅再次出手。设阵容有 x 组，每回合最多触发 x + 1 轮。 |
| 命中与成长 | 每只企鹅初始发射 5 枚雪球。目标从自身以外的动物中均匀抽取，第 2 次命中使目标冻结。触发冻结的企鹅从下次出手起永久多发 1 枚雪球。 |
| 冻结状态 | 每轮重新计数。最后一轮的残余冻结在回合交界清空。轮内冻结全场后，剩余雪球仍计入发射量。 |
| 随机数 | Mulberry32。命中与洗牌的种子分别为 20260828 + 100000 × x 和 96408241 + 100000 × x。固定组沿用同一命中规则和初始种子。 |

「全轮满冻结」要求触发到第 x + 1 轮，且每轮都让全场动物进入冻结。「首轮最大单只雪球占比」先算每条轨迹在首轮出手前雪球最多的一只企鹅占全队的比例，再取样本均值。

## 观察结果

表中每对数字按「每轮随机 / 固定顺序」排列。累计雪球统计当前回合内所有触发轮。

| 阵容 | 回合 | 全轮满冻结 | 平均累计雪球（枚） | 首轮最大单只雪球占比 |
| ---: | ---: | ---: | ---: | ---: |
| 2 组 | 1 | 5.5% / 6.0% | 22.564 / 22.437 | 50.0% / 50.0% |
| 3 组 | 3 | 94.8% / 89.1% | 238.351 / 233.403 | 42.2% / 46.7% |
| 5 组 | 1 | 0.1% / 0.1% | 157.310 / 155.966 | 20.0% / 20.0% |
| 5 组 | 3 | 99.0% / 98.3% | 878.058 / 878.093 | 30.5% / 39.5% |
| 5 组 | 30 | 100.0% / 100.0% | 10,598.358 / 10,598.742 | 23.6% / 86.2% |
| 6 组 | 30 | 100.0% / 100.0% | 17,320.310 / 17,314.367 | 20.1% / 87.7% |

首回合全轮满冻结的样本比例最高为 6.0%。主稿试算用的 5 组阵容中，两种顺序各有 1 条轨迹在首回合满足条件，到第 3 回合分别为 990 条和 983 条。启动后，全场冻结的近似更贴近这批样本中的循环。表中的 100% 表示采样中未观察到失败。

第 3 至 30 回合共有 140 组阵容与回合的配对。随机组首轮最大单只雪球占比在这 140 对中均低于固定组，而全队平均累计雪球数的相对差距最大为 2.12%（以固定组为分母）。当一轮冻住全场时，企鹅全队下一轮合计增加 2x 枚雪球，增加的雪球归给完成冻结的企鹅。固定顺序中，先出手的企鹅有机会完成更多目标的第 2 次命中。这解释了为什么队伍的雪球总数接近，个体的雪球数仍能明显分化。

[数值模型](../极地流-数值模型.xlsx)用完整冻结、脂肪平均分配的假设比较四种倍率规则。上述模拟仅统计冻结与雪球，用于判断完整冻结假设在哪些回合更接近随机实验中的情况。

## 复算

在本文件所在的 `验证` 目录运行以下命令。脚本只依赖 Python 3.10 或以上版本的标准库。

```sh
python "脚本/蒙特卡洛复算.py"
python "脚本/阶段得分复算.py" --groups 5 --stages 15
```

第一条命令会复现[出手顺序对照](数据/极地流_出手顺序对照.csv)和[固定顺序](数据/极地流_固定顺序.csv)两张表。复算[交互网页](../极地流-交互分析.html)中的自选实验时，输入同样的阵容、样本量和命中种子。

```sh
python "脚本/蒙特卡洛复算.py" --groups 5 --trials 500 --seed 123 --output "出手顺序试算.csv"
```
